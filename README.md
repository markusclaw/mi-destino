# Destino

Libro de Nohemi y Greg. La historia de los dos caminos que nos trajeron hasta aquí,
escrita como legado para nuestra familia, nuestros futuros hijos, y quien venga después.

**Estado:** borrador privado · en español · repositorio privado, sin publicar.

## Cómo está organizado

| Carpeta / archivo | Qué es |
|-------------------|--------|
| `LIBRO.md` | **Empieza aquí.** Índice completo: partes, capítulos, quién escribe cada uno y en qué estado va. También las alternativas de título. |
| `GUIA-DE-ESTILO.md` | Reglas cortas de voz y formato para que el libro suene a uno solo. |
| `manuscrito/` | El libro en sí. Un archivo por capítulo, en orden. Cada capítulo trae preguntas guía para arrancar. |
| `manuscrito/anexos/` | Cronología, versículos, lista de fotos. |
| `materiales/` | Materia prima: cartas, notas del teléfono, transcripciones de audios, fotos. Los originales no se editan. |
| `index.html` | Página de lectura (borrador). Más adelante se generará a partir de `manuscrito/`. |

## Cómo trabajamos

1. Elegir un capítulo en `LIBRO.md`.
2. Abrir su archivo en `manuscrito/` y responder las preguntas guía, aunque sea hablando (nota de voz → transcribir → pegar).
3. Cambiar el **Estado** del capítulo en el archivo y en `LIBRO.md`.
4. Guardar en git con un mensaje corto en español (ej. `Cap 2: primer borrador de Nohemi`).

## Decisiones tomadas
